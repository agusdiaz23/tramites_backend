# Sistema de Gestión de Trámites Backend

Proyecto backend desarrollado en Java utilizando Hibernate y PostgreSQL.

## Funcionalidades
- Gestión de usuarios, perfiles y trámites
- Sistema de eventos (observaciones, respuestas)
- Sistema de auditoría de cambios
- Carga de archivos
- Notificaciones internas
- Envío de emails automáticos
- Modelado de relaciones complejas (OneToMany, ManyToMany)
- Persistencia de datos

## Tecnologías
- Java
- Hibernate
- PostgreSQL
- Git
- JPA
